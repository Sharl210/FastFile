# FastFile 2.1

FastFile 是一个聊天式云端传输工具。你可以像发消息一样发送文本、图片、视频、音频和普通文件，所有内容都保留在同一个会话流里，适合个人传输、团队中转和轻量资料归档。

## 你能直接得到什么

- 文本和文件在同一个聊天流里混合展示
- 图片、视频、音频都能进入统一查看器连续浏览
- 长文本不会直接把聊天流撑爆，只显示摘要，点开再看全文
- 视频和音频会记住上次播放位置，重新打开能接着看
- 文件上传支持多文件、断点续传、取消上传、速度估算和后台任务面板

## 2.1 的重点体验

### 统一媒体查看器

- 图片、视频、音频共用一套查看器
- 支持上一条 / 下一条 / 关闭 / 键盘 ↑↓ 切换 / Escape 关闭
- 标题统一为 `文件名 [类型] (当前/总数)`
- 文件名过长时会自动用 `...` 截断，但类型和索引始终可见
- 外层消息卡片会按文件类型显示不同底色，便于快速区分图片、视频和音频

### 音频与视频更连续

- 视频播放进度会自动记忆
- 音频播放进度也会自动记忆
- 音频播放器支持横向进度条、竖向音量调节和移动端适配

### 长文本查看更安全

- 聊天流中超长文本只显示摘要，不会整段铺开
- 点击“查看更多”进入全文查看器
- 全文查看器支持上一条 / 下一条 / 复制 / 关闭
- 全文查看器会记住每条文本上次浏览到的行号，重新打开后可继续阅读
- 自动换行是全文查看器的全局选项，并会保存到云端
- 查看器支持内部文本缩放，不会直接劫持浏览器整页缩放
- 超长文本会按视口附近分块渲染，滚过的内容会回收前端渲染资源，降低浏览器压力

## 怎么使用

1. 打开 FastFile 页面并输入访问密码。
2. 直接发送文本，或者通过上传入口选择图片、视频、音频和普通文件。
3. 点击图片缩略图、视频封面、音频卡片或长文本的“查看更多”进入查看器。
4. 在查看器里继续切换上一条 / 下一条，浏览同一批内容。
