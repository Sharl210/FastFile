# FastFile 2.1

FastFile 是一个聊天式云端传输工具。你可以像发消息一样发送文本、图片、视频、音频和普通文件，所有内容都保留在同一个会话流里，适合个人传输、团队中转和轻量资料归档。

## 你能直接得到什么

- 文本和文件在同一个聊天流里混合展示
- 图片、视频、音频都能进入统一查看器连续浏览
- 长文本不会直接把聊天流撑爆，只显示摘要，点开再看全文
- 高压力的前端区域会优先只渲染可视范围附近，远处内容会回收，尽量避免浏览器因为长列表、长文本或超大输入而卡死
- 视频和音频会记住上次播放位置，重新打开能接着看
- 登录密码支持逗号分隔多个值，每个密码都会对应一个独立用户，聊天记录、播放进度和界面偏好彼此隔离
- 文件上传支持多文件、断点续传、取消上传、速度估算和后台任务面板

## 最近一轮性能与稳定性优化

### 统一媒体查看器

- 图片、视频、音频共用一套查看器
- 支持上一条 / 下一条 / 关闭 / 键盘 ↑↓ 切换 / Escape 关闭
- 标题统一为 `文件名 [类型] (当前/总数)`
- 文件名过长时会自动用 `...` 截断，但类型和索引始终可见
- 外层消息卡片会按文件类型显示不同底色，便于快速区分图片、视频和音频

### 音频与视频更连续

- 视频播放进度会自动记忆
- 音频播放进度也会自动记忆
- 音频播放器支持横向进度条、竖向音量调节和移动端适配
- 媒体文件接口支持按字节范围读取，音视频播放优先走浏览器原生按需加载，而不是前端主动整包预取

### 长文本查看更安全

- 聊天流中超长文本只显示摘要，不会整段铺开
- 点击“查看更多”进入全文查看器
- 全文查看器支持上一条 / 下一条 / 复制 / 关闭
- 全文查看器会记住每条文本上次浏览到的行号，重新打开后可继续阅读
- 自动换行是全文查看器的全局选项，并会保存到云端
- 查看器支持内部文本缩放，不会直接劫持浏览器整页缩放
- 超长文本会按视口附近分块渲染，滚过的内容会回收前端渲染资源，降低浏览器压力

### 前端渲染默认先保稳

- 聊天流在消息规模上来以后，会优先只保留视口附近的消息节点，远处消息改为占位撑高，减少 DOM 压力
- 文本查看器和高负载输入区沿用同一条原则，不追求把所有内容一次性铺到页面上
- 输入框和全屏草稿编辑器在遇到超大文本粘贴时，会分段写入，避免一次性塞入过多内容把前端主线程卡住
- 这套策略的目标不是“偷内容”，而是在完整滚动、完整查看、完整编辑都不丢的前提下，尽量把前端崩溃风险压低

### 数据库与轮询更克制

- 消息列表轮询现在会优先使用修订号和 `ETag`，没有变化时直接返回 `304`，避免反复把整段聊天记录从数据库读到前端
- 多用户登录后，每个用户只会读取自己的消息、进度和界面状态，避免无关数据互相干扰
- 数据库初始化会补齐当前版本需要的用户归属字段，老数据会在首次启动时迁到默认用户名下，降低手动整理成本

### 输入与上传更集中

- 输入框右侧提供全屏草稿编辑器入口，用来编辑当前本地草稿，不会混入上一条 / 下一条导航
- 普通输入框在草稿足够长时会切换到可视区域优先渲染；全屏草稿编辑器则重点保证超大文本粘贴和长时间编辑时不容易把页面拖死
- 超大文本粘贴不会一次性整块压进输入框或草稿编辑器，而是分段落入，尽量避免页面瞬间卡死
- 图片、视频、音频和普通文件上传都收敛到输入框旁边的加号菜单里

### 管理页更适合清理记录

- 管理页支持搜索与筛选叠加，只显示命中的消息
- 搜索会同时匹配文本内容和文件名
- 筛选支持全部、仅文字、仅文件、图片、视频、音频；处于非默认状态时会通过按钮颜色直接提示当前状态

## 怎么使用

1. 打开 FastFile 页面并输入访问密码。
2. 直接发送文本，或者通过上传入口选择图片、视频、音频和普通文件。
3. 点击图片缩略图、视频封面、音频卡片或长文本的“查看更多”进入查看器。
4. 在查看器里继续切换上一条 / 下一条，浏览同一批内容。
